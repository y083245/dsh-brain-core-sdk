# __ID__

A Brain Core process plugin generated by `create-brain-plugin`. It runs as a separate process and
talks to the kernel with JSON-RPC 2.0 over stdio (protocol v0).

## Run it by hand

```bash
uv run --no-sync python main.py
```

Type one JSON-RPC message per line on stdin. `initialize` answers with `{"apiVersion": "1.0.0"}`,
then the plugin announces its `hello` tool and sends `plugin.ready`. Stop it with `shutdown`.

## Check the plugin

Until `brain plugin check` ships, run the checker from the SDK repository root — in the plugin
directory, with `/path/to/brain-core` replaced by the repository's absolute path:

```bash
node --input-type=module -e "import { runCheckCli } from '/path/to/brain-core/packages/testkit/src/index.ts'; process.exit(await runCheckCli(['.'], { stdout: (t) => process.stdout.write(t), stderr: (t) => process.stderr.write(t) }))"
```

The manifest is checked; the contract test is skipped because it only runs for `runtime: node`. A
`notes:` section explains why; it is informational and does not affect `result: pass`. Once the
kernel ships, the same check is `brain plugin check`.

## The files

- `package.json` — the manifest lives in the `brain` section, including `runtime` and `process`.
- `pyproject.toml` — the kernel runs `uv sync --no-dev` when it installs the plugin.
- `main.py` — the protocol loop. Add new tools to `TOOLS` and register them in the manifest.
