# __ID__

A Brain Core plugin generated by `create-brain-plugin`.

## Run the tests

```bash
npm install
npm test
```

The test calls `runPluginContractTests` from `@dsh-brain-core/testkit`: it loads `apply` in a fake
kernel and checks the manifest, registration, unload and late-registration rules. It also calls the
`hello` tool; when the manifest has `memory.ingest` or `memory.record`, it checks the record the
plugin writes.

## Check the plugin

Until `brain plugin check` ships, run the checker from the SDK repository root — in the plugin
directory, with `/path/to/brain-core` replaced by the repository's absolute path:

```bash
node --input-type=module -e "import { runCheckCli } from '/path/to/brain-core/packages/testkit/src/index.ts'; process.exit(await runCheckCli(['.'], { stdout: (t) => process.stdout.write(t), stderr: (t) => process.stderr.write(t) }))"
```

It validates the manifest and runs the same contract plus the static rules (no own database, no
direct network, no DSH, no writes outside `ctx.storage`). A `notes:` section lists what a static
scan cannot see; it is informational and does not affect `result: pass`. Once the kernel ships, the
same check is `brain plugin check`, which the `check` script in `package.json` already calls.

## Before the packages are published

`@dsh-brain-core/sdk` and `@dsh-brain-core/testkit` are not on npm yet, so `^1.0.0` cannot be installed. In
the SDK repository, point the two dependencies at the local packages:

```json
"@dsh-brain-core/sdk": "file:/path/to/brain-core/packages/sdk"
```

```json
"@dsh-brain-core/testkit": "file:/path/to/brain-core/packages/testkit"
```

The first line replaces the dependency, the second one the devDependency. Then run `npm install`.

## What is here

- `package.json` — the manifest lives in the `brain` section; add every tool there. `main` points
  at `src/index.ts` so Node 24 can run the plugin without a build step; publish it as
  `dist/index.js` after adding a build if you put it on npm.
- `src/index.ts` — `apply`, which registers the `hello` tool.
- `src/config.ts` — the Schemastery schema the console uses to build a form.
- `test/plugin.test.ts` — the contract test.

See the `BrainContext` and manifest types exported by `@dsh-brain-core/sdk` before changing permissions or adding tools.
